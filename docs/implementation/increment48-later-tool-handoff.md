## Selected numerical references

- `RcFilter`: public two-terminal source with `R = 1 kOhm`, `C = 1 pF` and
  `I = V/R + C*dV/dt`. DC reference is `I = V/R`; small-signal admittance is
  `1/R + j*omega*C`. A transient bench must specify its excitation and loading
  before deriving the corresponding reference. Preserve parameter values and
  physical units rather than substituting a hand-written target model.
- `AnalogCapabilityStorage`: `initialStep` sets Boolean enable and Integer mode,
  then selects held voltage `1 V`. This supports an initialization/load observation
  only after F-049 demonstrates supported simulator event behavior. It does not
  establish independent monitor histories, crossing placement or transition rules.
- `AnalogLintSafeSource`: expected terminal voltage is
  `(3.5 + sin(t / 1 s)) V`; constant rounding contributes exactly `3`. Use actual
  generated bytes and a declared time grid and tolerance. Do not tune tolerances
  to hide a discrepancy.
- `AnalogContextSource`: expected voltage is
  `(T / Tnom + t / 1 s) V`, with both temperatures in kelvin. Record the simulator's
  actual temperature and nominal-temperature provider behavior before treating this
  as a numerical comparison. F-044 edition and portability distinctions still apply.
